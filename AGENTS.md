# Clear Creek Chiropractic

## Commands

- `npm run dev` — start the local Next.js dev server
- `npm run build` — create a production build
- `npm run start` — serve the production build

## Structure

- `src/app/` — App Router pages, metadata, and styles
- `public/images/` — downloaded Clear Creek brand and photography assets
- `next.config.ts` — typed Next.js configuration

Keep the homepage native to Next.js. Do not add iframes or remote page proxies.
